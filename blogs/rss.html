Ingesting the Real-Time Web: Building an RSS & Atom Feeds Connector for Cognee

By Mallikarjun R Published: October 2026 Hackathon: Mergetober 2026 Issue: #4804

Data feeds powered by RSS and Atom are the quiet backbone of the decentralized internet. Every technical publication, engineering changelog, research laboratory, and newsletter distributes updates using these open protocols. By bringing native RSS and Atom ingestion into Cognee, AI agents can continuously learn from the entire open web in real time.

Why RSS Matters for Cognitive Graphs

Most AI agents suffer from information cutoff: their world knowledge freezes the day training finishes. While scraping arbitrary HTML pages is brittle and prone to breakage, syndication feeds offer structured, canonical streams containing article titles, clean author attribution, timestamps, and full HTML or plain-text summaries.

Key Benefit: One connector covers thousands of content providers — Hacker News, Substack, ArXiv, GitHub releases, WordPress blogs, and corporate engineering publications — without requiring API keys or rate-limit gatekeeping.

Architecture and Design

The connector sits under packages/connector/rss/ and leverages Python's built-in xml.etree.ElementTree for high-performance, dependency-free XML parsing.

  • Dual Protocol Handling: Normalizes RSS 2.0 (<item>) and Atom 1.0 (<entry>) into uniform Cognee memory entities.
  • Document Mode Extraction: Tags every row with DOCUMENT_SOURCE_ATTR = "rss", directing article content directly into Cognee's cognitive graph pipeline for entity extraction and semantic indexing.
  • Incremental Synchronization: Evaluates publication timestamps against an optional since parameter to ingest only net-new articles.
  • Forget-on-Delete Lifecycle: Runs with write_disposition="replace" so pruned feed entries automatically trigger graph cleanup.

Quickstart Example

import asyncio
import cognee
from cognee_community_connector_rss import rss_source

async def main():
    # Ingest multiple syndication streams
    feeds = [
        "https://news.ycombinator.com/rss",
        "https://blog.langchain.dev/rss/",
    ]
    
    source = rss_source(feed_urls=feeds, max_entries_per_feed=25)
    
    await cognee.remember(
        source,
        dataset_name="tech_intelligence",
        primary_key="id",
        write_disposition="replace",
    )
    
    # Query your freshly updated graph memory!
    insights = await cognee.search("What are the latest breakthroughs in AI agents?")
    print(insights)

if __name__ == "__main__":
    asyncio.run(main())
