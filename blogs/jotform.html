Giving AI Agents Operational Intake Memory: Building a Jotform Connector for Cognee

Author: Mallikarjun R (@mallikarjunr444-gif) Target: topoteretes/cognee-community Resolves: #5968

Jotform is the default operating backbone for service requests, tenant intakes, survey forms, and customer registration across thousands of organizations. But once submitted, these forms typically languish in isolation. Without contextual AI memory, an agent answering user questions has no way to correlate past maintenance tickets, recurring equipment failures, or original customer requests.

To solve this, I designed and built the Jotform Data-Source Connector for Cognee during Mergetober 2026.

What Does the Jotform Connector Do?

The connector plugs into the official Jotform REST API to extract form definitions and submissions, translating raw field IDs (e.g. q17, q23) into natural, human-readable questions. Instead of an agent receiving cryptic key-value pairs, it receives structured narrative Markdown documents:

  • Form Metadata & Question Schema: Resolves question definitions and labels dynamically.
  • Human-Readable Field Mapping: Converts structured answers into clean question-answer documents.
  • Snapshot Synchronization: Full snapshot with write_disposition="replace" allowing Cognee's orphan_cleanup to prune deleted submissions.
  • Resilient HTTP Transport: Built-in exponential backoff on HTTP 429 rate limit responses.

Architecture & Cognify Integration

The connector declares cognee_document_source = "jotform". This routes every form submission directly through Cognee's document-mode entity extraction pipeline, building rich knowledge graphs connecting customers, equipment, addresses, and issues.

import asyncio
import os
import cognee
from cognee_community_connector_jotform import jotform

async def main():
    os.environ["JOTFORM_API_KEY"] = "your_api_key_here"
    
    # Ingest submissions from Jotform into Cognee graph memory
    await cognee.add(jotform(form_ids=["241234567890"]))
    await cognee.cognify()
    
    # Query your AI memory
    results = await cognee.search("Which properties reported recurring HVAC issues?")
    for res in results:
        print(res)

if __name__ == "__main__":
    asyncio.run(main())
